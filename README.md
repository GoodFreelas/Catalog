## 🏗️ Architecture

Fullstack application integrating with **Tiny ERP** for product data and **WhatsApp** for orders.

```mermaid
graph TD;
    User-->App[Catalog App];
    App-->API[Backend API];
    API-->TinyERP[Tiny ERP];
    App-->WhatsApp[WhatsApp Business];
```
